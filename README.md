# NovaFlow

A modern SaaS website designed to present a digital product, its features, benefits, pricing, and FAQs in a conversion-focused experience.

🔗 **Live demo:** https://novaflow-pi.vercel.app/

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Features
- Feature and pricing breakdown sections
- FAQ section
- Smooth animated transitions
- Fully responsive design
